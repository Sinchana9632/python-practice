# 🐍 Python Fundamentals & Core Practice

A comprehensive repository dedicated to mastering Python from the ground up—covering language mechanics, memory layouts, built-in data structures, and idiomatic Python coding practices.

---

## 🎯 Repository Overview

This repository tracks my core Python learning journey as part of my software engineering foundation. The goal is to build deep conceptual clarity on how Python operates under the hood, enabling me to write efficient, clean, and production-ready code.

---

## 🛠️ Concepts & Topics Covered

### 1. Python Basics & Execution Mechanics
- History, Features, and Applications
- Python Execution Model & Bytecode
- Variables, Data Types, and Type Conversion
- Operator Precedence & Associativity

### 2. Built-in Data Structures
- **Lists:** Dynamic Arrays, Methods, Mutability, Memory Overhead
- **Tuples:** Immutability, Memory Efficiency, Tuple Packing/Unpacking, Use as Hashable Keys
- **Sets:** Unordered Collections, Hashing Mechanism, Set Operations, Membership Testing ($O(1)$)
- **Dictionaries:** Key-Value Mapping, Hash Tables, Collision Resolution Basics, Lookup Performance ($O(1)$)

### 3. Advanced Python Features
- List, Set, and Dictionary Comprehensions
- Ternary Operators & Conditional Expressions
- Efficient Iteration with `enumerate()` and `zip()`
- Memory Optimization Techniques (List vs Tuple Layouts)
