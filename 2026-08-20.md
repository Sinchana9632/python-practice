In Python loops, there are three keywords used to control the flow of execution: **`break`**, **`continue`**, and **`pass`**.

  

### 1. `break` — "Stop everything and exit!"

`break` immediately **kills the loop**. The program stops running the loop entirely and jumps to whatever code comes _after_ the loop.

  

- **Analogy:** You are reading a book, hit a missing page, and decide to close the book completely and walk away.
    
      
    
- **Example:**
    
      
    
    Python
    
    ```
    for num in [1, 2, 3, 4, 5]:
        if num == 3:
            break  # Stop right here!
        print(num)
    
    # Output: 1, 2
    ```
    

### 2. `continue` — "Skip this step and go to the next one!"

`continue` skips only the **current iteration** of the loop. It stops executing the rest of the code inside the loop _for that specific turn_ and jumps straight to the next item in the loop.

  

- **Analogy:** You are reading a book, come across an advertisement page, skip that single page, and keep reading the next page.
    
      
    
- **Example:**
    
      
    
    Python
    
    ```
    for num in [1, 2, 3, 4, 5]:
        if num == 3:
            continue  # Skip 3 and move to 4
        print(num)
    
    # Output: 1, 2, 4, 5
    ```
    

### 3. `pass` — "Do nothing (Just a placeholder)"

`pass` is a **null statement**. It does literally nothing! It is used when Python requires code syntactically (like inside an `if` block or a function), but you aren't ready to write the code yet.

  

- **Analogy:** You leave a blank sticky note in your notebook to remind yourself to write something there later.
    
      
    
- **Example:**
    
      
    
    Python
    
    ```
    for num in [1, 2, 3]:
        if num == 2:
            pass  # Python ignores this and keeps going normally
        print(num)
    
    # Output: 1, 2, 3
    ```
    

### Quick Comparison Table

|**Keyword**|**What it does to the loop**|**Does the loop keep going?**|
|---|---|---|
|**`break`**|Terminates the loop completely|**No** (Exits immediately)|
|**`continue`**|Skips the rest of the current turn|**Yes** (Moves to next turn)|
|**`pass`**|Does nothing at all|**Yes** (Executes line by line)|

How does that feel? Try testing yourself: if you wanted to look through a list of numbers and stop as soon as you find a negative number, which one would you use?



  

### Python String Concepts & Methods

#### 1. Character Encoding with `ord()` and `chr()`

- **`ord(char)`:** Converts a single character into its integer ASCII code point.
    
      
    - Example: `ord('a')` $\rightarrow$ `97`
        
          
        
- **`chr(code)`:** Converts an integer ASCII code back into a character.
    
      
    - Example: `chr(97)` $\rightarrow$ `'a'`
        
          
        

#### 2. Fixed ASCII Frequency Array (`[0] * 26`)

- Used for frequency counting without hash maps/dictionaries.
    
      
    
- **Formula:** `index = ord(char) - ord('a')`
    
      
    - `'a'` $\rightarrow$ `97 - 97 = 0`
        
          
        
    - `'b'` $\rightarrow$ `98 - 97 = 1`
        
          
        
    - `'z'` $\rightarrow$ `122 - 97 = 25`
        
          
        
- Keeps auxiliary space strictly constant at $\mathcal{O}(1)$.
    
      
    

#### 3. Loop Range Tricks & Control Keywords

- **Preventing Index Out-of-Bounds:** `range(len(s) - 1)` ensures `s[i + 1]` stays within bounds when checking adjacent pairs.
    
      
    
- **Backward Traversal:** `range(len(s) - 1, -1, -1)` scans from the last index down to `0`.
    
      
    
- **Loop Controls:**
    
      
    - `break`: Exits the loop immediately.
        
          
        
    - `continue`: Skips the rest of the current turn and moves to the next.
        
          
        
    - `pass`: A placeholder that does nothing.
        
          
        

#### 4. Useful String Methods

- **`string.startswith(prefix)`:** Returns `True` if string begins with `prefix`, otherwise `False`.
    
      
    
- **`string.find(substring)`:** Returns starting index of `substring`, or `-1` if not found.
    
      
    
- **`string.split(separator)`:** Splits string into a list of words based on a delimiter.
    
      
    
- **`string.join(iterable)`:** Efficiently combines elements into a single string.
    
      
    

#### 5. String Slicing vs. Indexing Overhead

- **Slicing (`s[0:3]`):** Creates a brand-new string copy in memory ($\mathcal{O}(k)$ time and space).
    
      
    
- **Indexing (`s[0]`):** Reads character directly from memory ($\mathcal{O}(1)$ time and zero extra memory).
    
      
    

### Solved Practice Problems

#### 1. LeetCode 3110: Score of a String

Python

```
class Solution(object):
    def scoreOfString(self, s):
        total_score = 0
        
        for i in range(len(s) - 1):
            Sum = abs(ord(s[i + 1]) - ord(s[i]))
            total_score += Sum
            
        return total_score
```

- **Time Complexity:** $\mathcal{O}(N)$
    
      
    
- **Space Complexity:** $\mathcal{O}(1)$
    
      
    

#### 2. LeetCode 58: Length of Last Word

Python

```
class Solution(object):
    def lengthOfLastWord(self, s):
        total = 0
        
        for i in range(len(s) - 1, -1, -1):
            if s[i] != " ":
                total += 1
            elif total > 0:
                break
                
        return total
```

- **Time Complexity:** $\mathcal{O}(N)$
    
      
    
- **Space Complexity:** $\mathcal{O}(1)$
    
      
    

#### 3. LeetCode 242: Valid Anagram

Python

```
class Solution:
    def isAnagram(self, s: str, t: str) -> bool:
        if len(s) != len(t):
            return False
        
        counts = [0] * 26
        
        for i in range(len(s)):
            counts[ord(s[i]) - ord('a')] += 1
            counts[ord(t[i]) - ord('a')] -= 1
            
        for count in counts:
            if count != 0:
                return False
                
        return True
```

- **Time Complexity:** $\mathcal{O}(N)$
    
      
    
- **Space Complexity:** $\mathcal{O}(1)$
