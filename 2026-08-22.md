

### 1. Advanced List & String Slicing (`[start : stop : step]`)

- **Positive Step (`+1`, `+2`)**: Moves forward (left-to-right).
    
      
    
- **Negative Step (`-1`, `-2`)**: Moves backward (right-to-left).
    
      
    
- **`stop` bound**: Slicing **always excludes** the `stop` index (stops 1 element before).
    
      
    

### 2. `enumerate()` Function

- Used to get both the **index** (`i`) and the **value** (`char`) at the same time during a loop:
    
      
    
    Python
    
    ```
    for i, char in enumerate(strs[0]):
        # i = index (0, 1, 2...)
        # char = character ('f', 'l', 'o'...)
    ```
    

### 3. Substring Extraction Slicing (`[i : i + length]`)

- Extracting a fixed-length chunk from a string starting at index `i`:
    
      
    
    Python
    
    ```
    # Extracts m characters starting at position i
    slice_chunk = haystack[i : i + m]
    ```
    

### 4. Safe Range Boundary (`range(n - m + 1)`)

- Prevents going out-of-bounds when checking substrings of length `m` inside a string of length `n`:
    
      
    - If `haystack` length is $N$ and `needle` length is $M$, the last valid starting index is $N - M$.
        
          
        

These 4 building blocks form the foundation for almost every String & Array problem in Python!
